# Mac Interface Finder

Консольная утилита для быстрого поиска и анализа сетевых интерфейсов виртуальных машин на macOS. Скомпилирована для процессоров Apple Silicon.

## 🚀 Установка из DMG (Рекомендуемый способ)

1. Скачайте и откройте файл **`InterfaceFinder.dmg`**.
2. Перетащите иконку приложения в папку **Программы** (`Applications`).

### ⚠️ Важно: Первый запуск (Обход защиты macOS)
Так как приложение не подписано в Apple Developer, система macOS заблокирует его при обычном запуске. Чтобы разрешить работу:
1. Откройте папку **Программы** через Finder.
2. Нажмите на приложение правой кнопкой мыши (или двумя пальцами по тачпаду) и выберите **Открыть**.
3. В появившемся окне предупреждения нажмите кнопку **Открыть**.

### ❓ Если у Вас доступны только кнопки "Переместить в корзину" и "Готово"
Начиная с macOS 15 Sequoia принудительный запуск программы происходит немного по-другому
1. Нажмите на кнопку **Готово**
2. Откройте **Системные настройки**, перейдите по **Конфиденциальность и безопасность**, в самом низу этого меню разрешите запуск программы **InterfaceFinder**
3. Дополнительно разрешите запуск в всплывающем окне.
Готово!

## 💻 Как запускать в Терминале

Поскольку это консольная утилита, после установки вы можете запустить её командой:

```bash
/Applications/InterfaceFinder.app/Contents/MacOS/vmInterfacesFinderForMacTerminal
```

### ⚡ Как сделать короткую команду
Чтобы не вводить длинный путь каждый раз и запускать утилиту простым словом `interface-finder`, создайте символическую ссылку в системе. 

Выполните эту команду в Терминале **один раз**:

```bash
sudo ln -s /Applications/InterfaceFinder.app/Contents/MacOS/vmInterfacesFinderForMacTerminal /usr/local/bin/interface-finder
```

Теперь утилита доступна из любой папки вашего Mac по короткой команде:
```bash
interface-finder
```
